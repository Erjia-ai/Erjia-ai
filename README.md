## Selected Projects

### 🤖 MCP × Cadence — AI for Analog IC Design

I connected AI to Cadence through MCP and used it in an analog IC design workflow, exploring how agents can interact with professional engineering tools rather than staying inside a chat interface.

### 🚗 Reinforcement Learning & AI for Robotics

Working on learning-based control and autonomous robotics using a real RC-car platform. The system combines stereo vision, LiDAR and IMU sensing with a Jetson Orin Nano, including neural-network-based cone detection and onboard perception. The project brings together perception, decision-making, and control on a physical platform.

### 📟 Digital Oscilloscope

Built a digital oscilloscope combining hardware design, signal acquisition, processing, and embedded implementation. It gave me a stronger foundation in the electronics beneath the higher-level intelligent systems I work with today.
